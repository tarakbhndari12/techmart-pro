# TechMart Pro 🛒

A Python-based electronics shop management system designed to manage day-to-day retail operations through a desktop interface.

## 📌 Overview

TechMart Pro provides a centralised system for managing products, sales, purchases, expenses, staff records and business reports.

The application uses **Python and SQLite** for application logic and data management, with visual reporting and CSV export capabilities.

## ✨ Features

* 📦 Inventory and product management
* 🛒 Sales and purchase management
* 💰 Expense tracking
* 👥 Staff management
* 📊 Business reports and data visualisation
* 📁 CSV data export
* 💾 Database backup functionality
* 🗄️ SQLite database integration
* 🖥️ Desktop graphical user interface

## 🛠️ Technologies Used

* **Python**
* **Tkinter**
* **SQLite**
* **Pandas**
* **Matplotlib**
* **CSV**

## 📊 Analytics & Reporting

The application includes reporting and visualisation features to help monitor business performance and understand operational data.

These features provide a practical example of using Python to manage, analyse and present business data.

## 🚀 Getting Started

### Prerequisites

* Python 3.x
* Required Python libraries used by the application

### Run the Application

Clone the repository and run:

```bash
python techmart.py
```

## 🎯 Purpose

This project was developed as a practical application of Python programming, database management and business-oriented data handling.
